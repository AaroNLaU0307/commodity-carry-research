# Data provenance conventions

Raw data is never committed to this repository — it lives in `DATA_DIR` (see `src/config.py`, default `C:\Users\Aaron\quant-data\commodity-carry`, outside this repo and outside OneDrive; overridable via the `DATA_DIR` environment variable). What lives here in the repo instead:

- **`MANIFEST.md`** — one entry per retrieved file: exact request specification (dataset, schema, symbols, date range), SHA-256 checksum, size, and retrieval notes (e.g. any mechanical retry/chunking needed). Generated by `scripts/phase1a_build_manifest.py` from whatever `DATA_DIR` actually contains plus the pull's own run summary — never hand-written.
- **Checksums** for every file actually pulled, so integrity can be verified without needing to re-fetch or without needing write access to the Databento account that pulled it originally.
- **No vendor "signals" or "analytics" fields** — only raw price/volume/OI/reference data as licensed, consistent with the no-alpha-peeking discipline carried over from Phase 0.

## Phase 0 provenance (feasibility only, not a real pull)

Phase 0 verified feasibility via Databento's `metadata.get_cost` (quotes only) and 18 real single-row `timeseries.get_range` probes against `GLBX.MDP3` — never a bulk pull. Full record: `docs/DATA_FEASIBILITY_REPORT.md`'s addendum, `docs/SAMPLE_AUDIT.md`, `docs/samples/COST_LEDGER.md`.

## Phase 1a provenance (the real pull)

Executed under `preregistration/PREREGISTRATION.md` §12 steps 1-2, with re-instantiated spending guardrails (re-quote before pulling, ceiling check, continued `COST_LEDGER.md`). Script: `scripts/phase1a_pull_corpus.py` (plus retry scripts for schemas that hit transient server-side timeouts — see `data/MANIFEST.md`'s notes for exactly which requests needed retrying/chunking, and `docs/DATA_QA_REPORT.md` for what the delivered data actually looks like). Real data from this pull is loaded, counted, checksummed, and audited for integrity only — see Phase 1a's data-QA-vs-signal-path separation in the top-level README.

## Source

- **Dataset:** Databento `GLBX.MDP3` (CME Globex MDP 3.0).
- **Universe:** 18 CME futures, 4 sectors — see `docs/DECISION_MEMO.md` for the full symbol list and per-symbol history windows.
- **Schemas:** `ohlcv-1d` (daily bars), `statistics` (settlement price, open interest), `definition` (expiry calendar).
- **Date range:** 2010-06-06 through 2026-06-30 inclusive (locked, `PREREGISTRATION.md` §2).
